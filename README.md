# מערכת תפעול לעסק הפעלות וסדנאות: דמו לחיץ

דמו אינטראקטיבי של מערכת התפעול שאופיינה עבור **דניאל חסיד פרויקטים בחינוך**, חברה לחינוך חווייתי שמפעילה תוכניות למניעת חרמות, פעילויות ODT וסדנאות במוסדות חינוך ברחבי הארץ.

הפרויקט הוכן במסגרת הקורס **מערכות מידע ואוטומציות**, מכללת אונו, על ידי **רחלי רבין** (2026).

## מה רואים בדמו

הדמו מציג את שלושת הממשקים שאופיינו. בחירת המשתמש נעשית מהסרגל העליון:

| משתמש | מסכים |
|---|---|
| **דניאל, מנהל** | מרכז השליטה, כרטיס אירוע, יומן הפעלות, אירועים, מדריכים, ציוד, משובים, אלבומים, ועסקאות שנסגרו עם "צור אירוע" |
| **יואב, מדריך** (בנייד) | האירועים שלי, פרטי אירוע, סיום ההפעלה |
| **דנה, לקוחה** (בנייד) | דירוג ההפעלה, פירוט המשוב, מסך תודה |

הכפתור "תסריט הצגה" בסרגל העליון מציג מסלול מומלץ לסיור בדמו, ו"איפוס" מחזיר את הנתונים למצב ההתחלתי.

## חשוב לדעת

- **כל הנתונים בדמו בדויים:** שמות, מוסדות, טלפונים וסכומים. התאריך בדמו קבוע: יום שני, 12.10.2026.
- **הדמו אינו המערכת החיה.** המסכים של דניאל והמודולים התפעוליים מומשו בפורטל הפרטי של העסק, שרץ עם נתוני אמת ואינו ציבורי. ממשק המדריך, טופס המשוב ללקוח והסנכרון ל-Google Calendar אופיינו ואושרו בדמו הזה, ונמסרו ללקוח לביצוע בשלב הבא.
- הדמו הוא קובץ HTML אחד, בלי שרת ובלי בסיס נתונים. השינויים שעושים בו נשמרים רק עד רענון הדף.

## טכנולוגיה

HTML, CSS ו-JavaScript בקובץ אחד, בלי ספריות צד שלישי מלבד:
- גופנים: Rubik ו-Heebo מ-Google Fonts
- אייקונים: Lucide
